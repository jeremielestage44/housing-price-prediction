# Housing Price Prediction

Projet de Machine Learning visant à prédire la valeur médiane de logements en Californie avec une régression linéaire.

## Objectifs

- Explorer un jeu de données immobilier
- Comprendre la régression linéaire
- Implémenter un modèle avec NumPy
- Comparer avec Scikit-learn
- Évaluer les prédictions
